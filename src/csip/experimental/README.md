# CSIP Experimental Modules

Modul dalam direktori ini (`src/csip/experimental/`):
- `omni_router.py`: Router pengurai kueri teks interaktif berbasis aturan
- `scenario_duel.py`: Simulasi duel skenario dan sensitivitas kebijakan
- `text_constellation.py`: Proyeksi semantik teks 2D
- `universal_csv_xray.py`: Profiling eksploratori cepat untuk file CSV eksternal

## Status & Batasan Klaim
Modul-modul ini berstatus **EKSPERIMENTAL** dan ditujukan untuk eksplorasi interaktif pada Decision Studio.
Modul ini:
1. **BUKAN** merupakan bagian dari pipeline pemodelan prediktif inti (`csip.data` -> `csip.features` -> `csip.models` -> `csip.evaluation`).
2. **TIDAK** termasuk dalam klaim kompetensi inti SKKNI 299/2020.
3. **TIDAK** menggunakan agen AI, LLM, atau dependensi eksternal tertutup.
